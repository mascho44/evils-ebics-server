# Schema sources

Downloaded 2026-09-23, unchanged except normalized line endings. Original notices are retained.

- `h005/`: official [EBICS 3.0 H005 schema package](https://www.ebics.org/en/technical-information/ebics-schema), version 07-08-2017. Only response schema and its dependencies are included. Download usage terms apply; see the linked publisher page.
- `camt.053.001.08.xsd`: ISO 20022 schema supplied in SIX's [cash-management schema archive](https://www.six-group.com/dam/download/banking-services/standardization/sps/ig-cash-managment-xml-schemas-v2.0.2-en.zip).

Tests validate generated XML against these schemas. They do not constitute EBICS certification or verify every client-specific implementation guideline.
