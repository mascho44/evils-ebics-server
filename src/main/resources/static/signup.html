EVILS EBICS Server

Eigenen Sandbox-Mandanten anfragen

Eine eigene, isolierte Testbank mit eigenen Konten/Teilnehmern und einem eigenen Admin-Login für die Admin-Oberfläche. Die Anfrage wird von einem Systemadministrator geprüft und manuell freigegeben - das kann etwas dauern. Benutzername und Passwort für den Admin-Login bitte gleich hier festlegen; nach Freigabe damit einfach einloggen.
