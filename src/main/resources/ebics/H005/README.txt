Install the official EBICS H005 schema package here.

Required files are listed by EBICS.org:
- ebics_H005.xsd
- ebics_request_H005.xsd
- ebics_response_H005.xsd
- ebics_orders_H005.xsd
- ebics_types_H005.xsd
- ebics_keymgmt_request_H005.xsd
- ebics_keymgmt_response_H005.xsd
- ebics_signature.xsd
- xmldsig-core-schema.xsd

Do not rename the files. The official package is available from:
https://www.ebics.org/en/technical-information/ebics-schema
