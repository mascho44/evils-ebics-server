# Schema provenance

`pain.002.001.03.xsd` is the unmodified SWIFT-generated ISO 20022 schema (2009), downloaded on 2026-09-23 from Danske Bank's [ISO 20022 resources](https://danskeci.com/ci/transaction-banking/instructions/iso-20022-xml), [schema archive](https://danskeci.com/-/media/pdf/danskeci-com/iso-20022-xml/pain,-d-,002,-d-,001,-d-,03,-d-,xsd.zip). Original generation notice is retained; line endings are normalized.

HAC allocation follows the [official EBICS 3.0 HAC examples](https://www.ebics.org/en/technical-information/examples) (Examples_HAC_BTF.zip, June 2018). ISO schema validation alone does not validate all EBICS allocation rules. Tests separately check the host, partner, user, order number, action and original payment references.
